# EE146 Face Verification Project 

## Setup Instructions
To ensure our PCA math and feature extraction work the same on everyone's computer, please follow these steps:

1. **Clone the repository** to your local machine.
2. **Create a virtual environment**:
   - `python -m venv venv`
3. **Activate the environment**:
   - Windows: `.\venv\Scripts\activate`
   - Mac/Linux: `source venv/bin/activate`
4. **Install dependencies**:
   - `pip install -r requirements.txt`

## 🎯 Project Goals
* **Task**: Face verification using Computer Vision.
* **Method**: Implementing Principal Component Analysis (PCA) 
* **Significance**: Creating a low-cost alternative to technologies like Apple's FaceID.

## Expected Results
* Live demonstration of user registration and login.
* PCA result plots showing how faces are verified in "Face Space".
